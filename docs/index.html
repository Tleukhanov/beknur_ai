Мүмкіндіктер

Барлығы браузерде жұмыс істейді. Сервер қажет емес.

A* жол іздеу

10×10 торда бастапқы және соңғы нүктелерді қойып, қабырғалар сызыңыз. A* алгоритмі ең қысқа жолды табады.

Minimax шайқас

Кезекпен жүретін тактикалық шайқас. Айдаһар Minimax арқылы 4 қадам алға есептеп, өзіне тиімді шешім қабылдайды.

Gemini LLM қария

Google Gemini API арқылы жұмыс істейтін дана қария. Қазақ ертегілері стилінде қысқа жауап береді.

Интерактивті интерфейс

Ешқандай орнату қажет емес. Браузерде ашып, бірден ойнауға болады.

Таза веб-стек

HTML, CSS, JavaScript. Фреймворксыз, сборкасыз. GitHub Pages арқылы жарияланады.

Ашық код

Барлық код GitHub-та. Оқуға, өзгертуге, кеңейтуге еркін.

AI тақырыптары (3 апта)

Теория емес, нақты код ретінде жүзеге асырылған.

1-апта

Интеллектуалды агенттер

Ер Төстік пен Айдаһар — ортаға реакция беретін агенттер. Күй машинасы: шабуыл, қорғану, емделу.

2-апта

Іздеу және A*

Тордағы A* алгоритмі: эвристика (Манхэттен қашықтығы), ашық/жабық жиындар, ең қысқа жол.

4-апта

Адверсариалды іздеу

Minimax: Айдаһар өзіне ең тиімді әрекетті таңдайды, ал ойыншының ең жақсы қарсы әрекетін есептейді.

AI талдау

Әр тақырып кодта қалай жүзеге асырылған.

A* жол іздеу

Тордағы A*: эвристика, көршілерді қарау, жабық жиын, жолды қалпына келтіру. Қабырғалардан айналып өтеді.

Minimax + Alpha-Beta (идея)

Тереңдік 4 деңгейде шешім ағашы. Бағалау функциясы: Айдаһар HP − Ер Төстік HP. Қажет болса емделу.

Generative AI (LLM)

Google Gemini API: systemInstruction арқылы «дана қария» рөлі. Қазақ тілінде, ертегі стилінде 1–3 сөйлем.

Күй машинасы

Шайқаста күйлер: шабуыл, қорғану, емделу. Әр әрекет күйді өзгертеді, HP жаңартылады.

Эвристика

Манхэттен қашықтығы: |x1−x2| + |y1−y2|. Тор үшін ең қарапайым және дәл эвристика.

API интеграциясы

fetchWithRetry: 429 қатесінде экспоненциалды күту. Чат тарихы контекст ретінде жіберіледі.

Архитектура

Бір HTML файлдағы модульді құрылым.

index.html      лендинг (осы бет)
play.html       интерактивті ойын
style.css       жалпы стильдер
script.js       ленивая загрузка видео

Ойын модульдері (play.html ішінде):
A* module       тор, эвристика, іздеу
Minimax module  шайқас, шешім ағашы
LLM module      Gemini API, чат тарихы
UI module       табтар, модальдар, рендер

Технологиялық стек

HTML5 CSS3 JavaScript (ES6) Tailwind (оригинал) Google Gemini API GitHub Pages
